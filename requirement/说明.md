---
  这套系统完整的交易逻辑

  一、这套系统在干什么？

  想象你雇了一个全天候盯盘的助手，每 15 分钟看一次行情，然后告诉你："现在应该买"、"应该卖"、或者"先等等"。这套系统就是这个助手——它有两种工作模式：

  - 技术分析模式：像一个经验丰富的图表分析师，用 11 种不同的指标"投票"
  - 量化因子模式：像一个数据科学家，综合技术、情绪、宏观经济、基本面四类信号打分

  ---
  二、它怎么看行情？（数据输入）

  每 15 分钟，系统从 IBKR（盈透证券）拿到最新的一根 K 线：这根 K 线包含这 15 分钟内的开盘价、最高价、最低价、收盘价和成交量。

  系统永远只看最近 500 根 K 线（约 48 个交易日），把更早的数据扔掉，保证计算速度和信号的时效性。

  另外，系统还会额外获取外部数据：
  - 恐慌指数 VIX（市场有多恐慌）
  - 美元指数 DXY（美元强弱）
  - 国债利差（10年 - 2年利率，经济衰退预警指标）
  - 联邦基金利率（美联储利率政策）
  - 公司基本面（PE 市盈率、营收增长，但只用已公开的历史数据，不会用未来的数据——这是本次修复的重要一点）

  ---
  三、它怎么判断市场状态？（四种环境）

  在分析具体信号之前，系统先判断"现在是什么市场环境"：

  ┌──────────┬──────────────────────────────┬────────────────────────────────┐
  │   状态   │           通俗理解           │            系统行为            │
  ├──────────┼──────────────────────────────┼────────────────────────────────┤
  │ 趋势平稳 │ 股价单边上涨或下跌，波动不大 │ 正常交易，趋势指标权重高       │
  ├──────────┼──────────────────────────────┼────────────────────────────────┤
  │ 趋势剧烈 │ 单边走势但价格跳动很大       │ 谨慎交易，适当缩小仓位         │
  ├──────────┼──────────────────────────────┼────────────────────────────────┤
  │ 震荡盘整 │ 价格在区间内来回             │ 反转策略为主                   │
  ├──────────┼──────────────────────────────┼────────────────────────────────┤
  │ 混沌剧烈 │ 无规律的大幅跳动             │ 提高进场门槛，大多数时候不交易 │
  └──────────┴──────────────────────────────┴────────────────────────────────┘

  就像不同天气穿不同衣服，不同市场环境用不同策略。

  ---
  四、它怎么产生买卖信号？

  技术分析模式（11 个指标投票）

  11 个指标各自给出 +1（看涨）、0（中性）、-1（看跌），然后加权求和得到一个 -1 到 +1 之间的总分：

  ┌──────────┬─────────────────────────┬────────────────────────────┐
  │   类别   │        具体指标         │          在问什么          │
  ├──────────┼─────────────────────────┼────────────────────────────┤
  │ 趋势     │ EMA 均线交叉、MACD、ADX │ "价格在往哪个方向走？"     │
  ├──────────┼─────────────────────────┼────────────────────────────┤
  │ 动量     │ RSI、KDJ、CCI、变化率   │ "涨势/跌势还有劲吗？"      │
  ├──────────┼─────────────────────────┼────────────────────────────┤
  │ 波动率   │ 布林带                  │ "价格是否偏离了正常范围？" │
  ├──────────┼─────────────────────────┼────────────────────────────┤
  │ 成交量   │ OBV、VWAP               │ "这个方向有资金支撑吗？"   │
  ├──────────┼─────────────────────────┼────────────────────────────┤
  │ 支撑阻力 │ 枢轴点                  │ "现在在关键价格位附近吗？" │
  └──────────┴─────────────────────────┴────────────────────────────┘

  分数超过 0.4 → 买入，低于 -0.4 → 卖出（默认阈值）

  还有一个"防抖"机制：信号必须连续 5 根 K 线都一致，才真正触发——避免因一根异常K线而冲动下单。

  量化因子模式（四类信号综合评分）

  更复杂的版本，用 AI 学习历史规律给每个因子分配权重：

  - 技术因子：上面11个指标的升级版，用数学公式量化
  - 情绪因子：VIX 恐慌指数、期权市场隐含情绪
  - 宏观因子：国债利差、美元强弱、利率环境
  - 基本面因子：公司估值、营收增长

  系统会分析"哪个因子过去预测得最准"，给准确率高的因子更高权重（IC 信息系数加权）。

  五、它怎么决定买多少？（仓位管理）

  不是每次都买一样多，而是根据风险来决定：

  核心公式（通俗版）：
  ▎ 我最多愿意亏多少钱（默认总资金的 2%）÷ 如果判断错了可能每股亏多少（用 ATR 波动幅度估算）= 可以买几股

  信号越强（评分越接近 ±1），买的越多；信号越弱，买的越少。同时还有两个上限保护：
  - 任何单笔不超过总资金的 20%
  - 总杠杆不超过 2 倍

  ---
  六、它怎么控制风险？（三道防线）

  第一道：单笔止损/止盈
  每开一笔仓，就自动设好三个退出条件：
  - 止损：亏损超过开仓时波动幅度的 2 倍 → 立刻止损
  - 止盈：盈利超过开仓时波动幅度的 4 倍 → 锁定利润
  - 跟踪止损：盈利中途回撤超过 1.5 倍波动幅度 → 保住大部分利润退出

  第二道：组合熔断器（本次修复了此问题）
  如果账户总体从最高点回撤超过 10%，系统自动停止开新仓，等 200 根 K 线（约 2 天）后，如果回撤恢复到 5% 以内，才重新交易。修复前：一旦触发就永远停止交易，这显然不合理。

  第三道：保证金预警
  如果账户保证金不足，强制平仓避免爆仓。

  七、它怎么模拟交易成本？

  真实交易有摩擦成本，系统精确复刻了盈透证券的收费：

  ┌──────────────┬─────────────────────────────────────────────┬──────────────────────────┐
  │     费用     │                  具体数值                   │           备注           │
  ├──────────────┼─────────────────────────────────────────────┼──────────────────────────┤
  │ 佣金         │ 每股 $0.0035，最低 $0.35                    │ IBKR 美股分级收费        │
  ├──────────────┼─────────────────────────────────────────────┼──────────────────────────┤
  │ SEC 监管费   │ 每百万美元卖出收 $8                         │ 只在卖出时收             │
  ├──────────────┼─────────────────────────────────────────────┼──────────────────────────┤
  │ FINRA 交易费 │ 每股 $0.000166（本次从旧费率更新）          │ 最高 $7.27               │
  ├──────────────┼─────────────────────────────────────────────┼──────────────────────────┤
  │ 滑点         │ 可配置，默认 5 个基点                       │ 买卖价差损耗             │
  ├──────────────┼─────────────────────────────────────────────┼──────────────────────────┤
  │ 融资利息     │ 动态 SOFR 利率 + 利差（本次修复为动态获取） │ 空仓做空或融资买入时计收 │
  ├──────────────┼─────────────────────────────────────────────┼──────────────────────────┤
  │ 融券费       │ 可配置 HTB 费率（本次新增）                 │ 做空难借股票时额外收取   │
  └──────────────┴─────────────────────────────────────────────┴──────────────────────────┘

  八、它的回测是怎么工作的？

  "回测"就是用历史数据模拟，看如果过去用这套策略，结果会怎样。

  系统会：
  1. 拿历史 K 线数据，从头开始逐根"回放"
  2. 每根 K 线按上面的逻辑判断买卖
  3. 买入时用"限价单"模式（挂单，下一根K线能成交才算成交）
  4. 精确扣除所有费用
  5. 最后输出一份完整报告：总收益、年化夏普比率、最大回撤、各时段表现等

  还有"参数优化"功能：把历史数据分成多段，在每段前半段找最好的参数，用后半段验证——避免参数只在历史上好看、实盘表现差（过拟合）。

  ---
  九、实盘交易流程（简化版）

  每15分钟 → 收到新K线
    → 判断市场状态（4种环境）
    → 11个指标投票 或 4类因子打分
    → 信号连续5根K线一致？
      → 是 → 开仓时间过了开盘30分钟？
                 → 是 → 账户有足够保证金？
                          → 是 → 计算仓位 → 下限价单
      → 否 → 继续等待

  开盘头 30 分钟不交易——因为开盘时市场波动异常，信号可靠性低。

  十、现在你可以提什么想法？

  这套系统目前的主要特点和可以改进的方向：

  目前做得好的：
  - 有完整的成本模型（大多数回测系统忽略这个）
  - 有市场环境识别（不同环境用不同策略）
  - P0 缺陷已全部修复（数据不再使用未来数据、仓位管理边界安全、熔断可恢复）

  你可以考虑提出想法的方向：
  - 交易哪些品种？（目前主要针对美股）
  - 信号的进场门槛是否合适？（0.4 这个分数阈值）
  - 止损/止盈的倍数是否符合你的风险偏好？（2倍/4倍/1.5倍 ATR）
  - 是否要加入某些你认为重要的信号来源？
  - 回测的时间段和标的是否覆盖你感兴趣的市场？
  - 是否要支持做空？（目前架构支持，但 HTB 费用等实盘细节刚刚加入）
